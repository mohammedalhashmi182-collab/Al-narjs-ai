أوامر قابلة لإعادة التشغيل من جذر المستودع بعد تثبيت تبعيات `pyproject.toml` وChromium عبر Playwright.

```bash
python -m pytest -q --disable-socket --allow-unix-socket
RUN_BROWSER_TESTS=1 python -m pytest -q tests/test_public_mobile.py tests/test_home_intro.py tests/test_voice_aurora.py --disable-socket --allow-unix-socket
ruff check --select E,F,I,UP,W --ignore E501 src/white_label tests/test_white_label.py
mypy src/white_label
python -m pip_audit
python -m bandit -r src -ll
```

تظل جودة الصوت الحي، قياس الأداء الميداني، المراجعة اليدوية لـWCAG، استعادة نسخة بيانات مشفّرة خارج Neon، وأذونات القنوات على حساب اختبار بوابات مستقلة. خدمة Render الحالية مرتبطة بـ`main` وتوليد Preview فيها معطل. المعاينة المنفذة لهذه الشريحة محلية ومعزولة.
