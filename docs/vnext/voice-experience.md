# تجربة مستشار النرجس الذكي

تعمل الصفحة في `/ar/voice` و`/en/voice` باتجاه الكتابة المناسب لكل لغة. تتبع الواجهة حالة الاتصال والاستماع والتفكير والتحدث والكتم والانتهاء. يستخدم عرض موجات الصوت رموز الألوان المشتركة وأشرطة عالية الوضوح مع احترام إعداد تقليل الحركة. مكالمة الصوت اختيارية وتُفتح بالنقر على زر البدء.

## مسارات الصوت والنص

| المسار | التنفيذ | عرض الإشارة |
| --- | --- | --- |
| صوت المتصفح الافتراضي | Web Speech للتعرّف والنطق. يرسل النص إلى `POST /api/voice/reply`، عبر سلسلة النماذج الموجودة. تظل اللغة `ar-SA` أو `en-US` بحسب الصفحة. | أشرطة ثابتة وحالة نصية. Web Speech لا يتيح عينات الصوت للصفحة. |
| جلسة xAI الاختيارية | تفعيل `XAI_VOICE_ENGINE=xai` مع الإعدادات الحالية. يصدر `POST /api/voice/session` رمزًا مؤقتًا للجلسة، ويستخدم الموقع الوكيل المنشور عبر WebSocket. | تُقاس عينات الميكروفون أو صوت الرد محليًا عبر Web Audio. يتوقف تحديث الأشرطة عند الكتم أو الدردشة أو تقليل الحركة. |
| الدردشة النصية | يحافظ اتصال xAI المفتوح على سياق الجلسة لدى المزود. خارج ذلك الاتصال تُرسل الرسائل إلى `POST /api/voice/reply`. | تعرض المحادثة الرد كتابةً دون تشغيله صوتيًا أو طلب الوصول إلى الميكروفون. |

يوقف التحول إلى الكتابة التقاط الميكروفون وتشغيل الردود. في المسار الافتراضي تُنهى المكالمة وتظل المحادثة النصية متاحة. في جلسة xAI يمكن العودة إلى التقاط الصوت بضغط زر «رجوع للصوت». ينظف إنهاء المكالمة أو مغادرة الصفحة مصادر الصوت والمؤقتات، ويوقف مسار الميكروفون الذي قد يصل متأخرًا من طلب إذن معلق. أخطاء الاتصال والإذن والتعرّف تظهر للمستخدم برسائل محلية مختصرة. نص المزود الخام غائب عن رسائل الخطأ وسجل المتصفح.

## الهوية والتأهيل والخصوصية

- تأخذ التحية وتعليمات الهوية من الخدمة. جاء توحيد الهوية في التغييرين `4a617d25ac7ef7e67057bf30c3bc133a341989c8` و`a4587152430c584665c871e1b14776778c1a672f` في [PR #174](https://github.com/mohammedalhashmi182-collab/Al-narjs-ai/pull/174). كيّف الفرع الاسم المعتمد «مستشار النرجس الذكي» لمساري الصوت الحاليين.
- يطرح المستشار سؤال تأهيل واحد في كل مرة، ويعرض التشخيص الأولي المجاني ويحيل إلى `/consult` للمتابعة المنظمة. الأسعار الشهرية من الكتالوج البرمجي. التجارب الخاصة لا تُعلن كعروض عامة.
- تحفظ الواجهة النص المعروض وسياق أحدث ثماني رسائل في ذاكرة الصفحة. مسار الرد يرسل السياق النصي إلى واجهة الرد. قد يعالج المتصفح أو مزود الصوت الكلام، كما يوضح التنبيه قبل البدء. يتطلب تسجيل فرصة أو ربطها بمشروع استخدام نموذج الاستشارة أو صلاحيات النظام القائمة.
- يبقى مفتاح xAI على الخادم. تحكم إعدادات مزود المتصفح في جودة النطق واللهجة، وتتحكم لوحة xAI في الصوت المنشور. التحقق المباشر من اللهجة والوضوح وسلوك المزود على شبكة فعلية مطلوب في بيئة الاعتماد.

## التحقق المحلي

اختبر Chromium بالعربية على عرض 320 بكسل وبالإنجليزية على عرض 1280 بكسل، مع رفض الميكروفون عبر محاكاة Web Speech وتحقق من الانتقال إلى الكتابة وإبقاء النص صامتًا. اختبر مسار xAI باستخدام WebSocket محاكى وإشارة حقيقية داخل Web Audio، شملت استجابة الأشرطة للإشارة وكتم المسار وإيقافه عند الانتقال للدردشة. تغطي اختبارات الواجهة البرمجية رمز الجلسة المؤقت، وتجاوز تحية المزود غير المعتمدة، واللغة، وحدود المكالمات، وسياسات المتصفح. تستدعي هذه الاختبارات خدمات محلية ومزودين محاكيين.

```sh
RUN_BROWSER_TESTS=1 BROWSER_EXECUTABLE_PATH=/usr/bin/chromium \
python -m pytest -q tests/test_voice_aurora.py tests/test_voice_live_csp.py tests/test_voice_public.py tests/test_voice_reply.py --disable-socket --allow-unix-socket
```
