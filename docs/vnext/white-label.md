# تخصيص العلامة وترخيصها

تبدأ خدمة العلامة من `src.white_label.app:create_app`. تنشر كعملية مستقلة عن Managed SaaS. تخدم صفحتي اللغة، CSS للعلامة وشعار PNG اختياريًا، وتعطي 404 للمسارات التشغيلية. لا تُحمّل هذه الخدمة بوابة العميل أو بيانات الفوترة أو مقدمي الذكاء الاصطناعي.

## إعداد عميل

1. جهّز ملف JSON خارج Git، وامنع الكتابة فيه إلا لمشغل النشر. حدّد `mode` بقيمة `hosted` أو `standalone`، ومصفوفة `tenants` فيها عنصر واحد إذا كان الوضع مستقلًا.
2. لكل سجل أضف `tenant_id`، و`domain` باسم DNS مملوك للعميل، و`brand` مع `name_ar` و`name_en` و`description_ar` و`description_en` و`support_email`. الإعدادات الاختيارية هي `default_language` و`accent` و`logo_png`. عند تفعيل الشعار، ضع `brand_assets/<tenant_id>.png` بجانب الملف. الحد 256 كيلوبايت وأسماء المستأجرين فريدة.
3. بعد توقيع الشروط، اضبط `license.state` على `active` و`license.expires_on` على تاريخ ISO. يوم الانتهاء محسوب بتوقيت الرياض ومشمول في الفترة. الحالات الأخرى `pending` و`suspended` و`revoked`. الإتاحة تحتاج أيضًا `features.public_brand_page: true`، وقيمتها الافتراضية معطلة.
4. اضبط `NARJIS_WHITE_LABEL_MANIFEST` في بيئة هذه الخدمة فقط. شغّل `python -m src.white_label` للتحقق من الإعداد، ثم استخدم مدخل ASGI أدناه. تغيير إعداد عميل أو تعليق ترخيصه يتطلب إعادة تشغيل مضبوطة للإعداد. التواريخ يعاد التحقق منها في كل طلب.
5. بعد التحقق من ملكية النطاق لدى المالك، فعّل TLS على بوابة تخص هذه الخدمة. اربط النطاق بالبوابة التي ترفض أسماء المضيفين غير المسجلة وتحافظ على ترويسة Host. الترويسات المرسلة من العميل مثل `X-Forwarded-Host` و`X-Tenant-Id` لا تحدد العميل. اختبر الصفحة والأصول والنطاقين في الاتجاهين، ثم وثّق تاريخ التفعيل والموافقة في السجل التشغيلي.

```bash
uvicorn src.white_label.app:create_app --factory --host 127.0.0.1 --no-proxy-headers --no-access-log
```

تُرفض نطاقات النرجس الحالية والقديمة وفروعها في هذا الإعداد. يستعمل العميل في وضع `standalone` ملفًا منفردًا وأصولًا تخصه وبيئة لا تشير إلى خدمات النرجس. لا تنسخ ملفات البيئة أو البيانات أو النسخ الاحتياطية أو تاريخ Git إلى توزيعة تجارية. اربط أي ميزات مستقبلية بمستأجر مصادق، مع حفظ سجل تغييرات الترخيص وتدوير أسرار العميل كتوسعة لاحقة.

## الحدود التجارية

- Hosted White-Label مرجعه 4,900 ريال للإعداد و1,490 ريالًا شهريًا.
- Standalone مرجعه 9,900 ريال للإعداد و1,000 ريال شهريًا للدعم الاختياري.
- البيع بدفعة واحدة يحتاج موافقة على مدة الاستخدام والتوزيع والدعم وملكية الإضافات. ينص نموذج الخدمة الحالي على استخدام داخلي غير قابل للنقل، لذلك يلزم عقد White-Label منفصل عند بيع حق إعادة البيع.
- تفعيل الحالة في الملف تفويض تشغيلي من المالك. لا يوجد إصدار تلقائي للعقود أو تحصيل أو إدارة كراسي مستخدمين أو DRM. قبل التوزيع، راجع تراخيص الحزم والأصول والأوزان وشروط مقدمي الخدمات.
