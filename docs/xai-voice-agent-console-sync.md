# النرجس AI — مزامنة الوكيل الصوتي مع xAI/Grok Bot

## ما تغير في هذا PR
- واجهة الموقع العربية والإنجليزية: لم يعد هناك Intro يغطي الشاشة أو كرة برتقالية. واجهة صوتية أصلية، مؤثر موجات أبيض/رمادي حي يعتمد على مستوى صوت WebSocket.
- تعليمات **الجلسة** المرسلة من الموقع إلى xAI عبر `session.update` بعد `session.created`: تعريف مستشار النرجس، التقاط احتياج العميل، اقتراح فريق متخصص، عدم ادعاء إنجاز لم يحدث أو طلب بيانات حساسة، دعوة الاستشارة الرسمية.
- لم تتغير معرفات الوكيل المنشور أو أسرار xAI أو آليات الفوترة.

## ما لم يتغير
يملك xAI Console إعدادات مستقلة للتحية الافتتاحية والاختيار الفعلي للصوت. لا توجد صلاحية من حساب ChatGPT هذا لتعديل إعدادات Grok Bot أو الوكيل المنشور في لوحة xAI؛ لذلك **لا يُدّعى تحديث التحية أو الصوت في لوحة المزود**.

## عند توصيل صلاحية xAI لاحقًا
1. افتح لوحة [Voice Agents في xAI](https://console.x.ai/) بنفس الحساب الذي يحتوي على `XAI_VOICE_AGENT_ID`، وتحقق من الوكيل الصحيح.
2. اجعل التحية متوافقة مع اسم النرجس: «حياكم الله، نورتوا النرجس. كيف ممكن أساعدكم؟». تجنّب أسماء مقدّمي النماذج أو ادعاء هوية بشرية.
3. اختر صوتًا شبابيًا ناعمًا من الخيارات **المتاحة فعلًا** في الحساب؛ لا تستعمل استنساخ صوت شخص من دون إذنه ولا تدّعِ وجود إعداد صوت لم يتم فحصه.
4. اربط الدور بتشخيص الطلب، سؤال واحد مفيد بكل دور، اقتراح الوكلاء المناسبين وإحالة إلى `/consult`، مع الإفصاح عن عدم توفر التكاملات غير المنشورة وعدم تقديم وعود دفع أو تسليم لا يوجد عليها إثبات.
5. اختبر جلسة عربية وإنجليزية على شبكة حقيقية مع ميكروفون وصوت مُعاد، وتحقق من عدم بدء تحية مزدوجة من إعدادات المزود والرسالة التي ترسلها الصفحة. افحص الرصيد والاستهلاك ضمن الحدود قبل الإطلاق.

## بوابات قبول النشر
- CI + Chromium على عرض 320px و390px و1280px مع دعم reduced motion.
- لا تحكم بالجاهزية الصوتية من نجاح HTML فقط: تحقق من جلسة xAI اختبار حقيقية وصوت دخول وخروج، أو سجّل «غير متاح» بوضوح.
- لا مفاتيح أو كلمات مرور داخل GitHub أو Notion؛ لا تعديل Render أو main قبل الموافقة.
